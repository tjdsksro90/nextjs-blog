티스토리 대신 직접 만든 블로그에 글을 쓰기로 했다. 글은 `src/content/posts` 폴더의 `.mdx` 파일 하나가 곧 글 하나다.

## 새 글 쓰는 방법

1. `src/content/posts/` 에 `파일이름.mdx` 를 만든다. 파일 이름이 주소가 된다. (`/posts/파일이름`)
2. 맨 위에 frontmatter를 적는다.
3. 아래에 마크다운으로 본문을 쓴다.

```yaml title="frontmatter 예시"
---
title: 글 제목          # 필수
date: 2026-11-05        # 필수, YYYY-MM-DD
description: 한 줄 요약  # 목록에 보임
tags: [React, CSS]
draft: true             # 초안: 개발 서버에서만 보임
---
```

## 지원하는 문법

| 문법 | 예시 |
| --- | --- |
| 굵게 | **bold** |
| 취소선 | ~~strike~~ |
| 인라인 코드 | `const a = 1` |

- [x] 표, 체크리스트 같은 GitHub 문법
- [x] 코드 블록 문법 강조
- [ ] 댓글

### 코드 블록

언어 뒤에 `title="..."`을 붙이면 파일 이름이 보이고, 줄 끝에 `// [!code highlight]`를 달면 그 줄이 강조된다.

```tsx title="Hello.tsx"
export function Hello({ name }: { name: string }) {
  const greeting = `안녕하세요, ${name}님`; // [!code highlight]
  return <p>{greeting}</p>;
}
```

바뀐 줄은 `// [!code ++]`, 지운 줄은 `// [!code --]`로 표시한다.

```ts
const total = price * count; // [!code --]
const total = price * count * (1 - discount); // [!code ++]
```
